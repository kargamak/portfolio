# Ufuk Eren Kurt - Kişisel Portfolyo & Proje Hub'ı

Yönetim Bilişim Sistemleri (YBS) öğrencisi ve ürün yöneticisi / sistem analisti **Ufuk Eren Kurt** için tasarlanmış modern, sade ve yüksek performanslı kişisel portfolyo ve proje merkezi.

## 🚀 Öne Çıkan Özellikler

- **Tasarım Çizimi Uyumu**: Sade, göz yormayan mat slate tema, mor çerçeve sınırları ve karakteristik hap butonlar.
- **Proje Hub'ı**: Canlı projeler (**Listor**, **Memory Line**, **FinAI**, **PixelCam**) için doğrudan erişim ve detay modalları.
- **Europass CV Entegrasyonu**: Deneyimler, eğitim, topluluk liderliği (AkdeMIS) ve yetenekler matrisi.
- **Türkçe / İngilizce Hakkımda**: Çift dil destekli biyografi alanı.
- **CV Yazdırma & PDF Desteği**: Tek tıkla tarayıcı üzerinden CV yazdırma veya PDF olarak kaydetme.
- **Mobil & Masaüstü Uyumlu**: Tamamen responsive (Tailwind CSS v4).

## 🛠️ Kullanılan Teknolojiler

- **React 19**
- **Vite 8**
- **Tailwind CSS v4**
- **Lucide React** (İkonlar)
- **Framer Motion & Canvas Confetti**

## 💻 Kurulum ve Çalıştırma

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# Canlı üretim derlemesi alın
npm run build
```

## 📝 İçerik Yönetimi

Tüm açıklamaları, proje linklerini, CV maddelerini ve iletişim kanallarını tek bir dosyadan yönetebilirsiniz:
`src/data/siteData.js`
